**2. Local Social Proof**
- "Completed 50+ projects in Kerikeri"
- "Trusted by Kerikeri builders and developers"
- "Familiar with Far North District Council requirements"

**3. Local Keywords Throughout**
- First paragraph: "Looking for a [service] in [location]?"
- H2: "[Service] in [Location]"
- H3: "Why Choose [Your Company] for [Service] in [Location]"
- Naturally mention location 8-12 times per page

**4. Local Schema Markup**
```json
{
  "@type": "Service",
  "name": "TP58 Wastewater Design",
  "areaServed": {
    "@type": "City",
    "name": "Kerikeri",
    "containedIn": "Northland"
  }
}
```
